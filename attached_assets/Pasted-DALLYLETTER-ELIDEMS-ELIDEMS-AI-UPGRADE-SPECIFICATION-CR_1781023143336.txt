DALLYLETTER ELIDEMS – ELIDEMS AI UPGRADE SPECIFICATION

CRITICAL INSTRUCTION

Upgrade the existing Dallyletter Elidems application without removing, replacing, modifying, or breaking any existing features, modules, databases, permissions, workflows, dashboards, reports, payment systems, user roles, settings, or integrations.

This is an enhancement project only.

All existing functionality must continue working exactly as before.

Before creating any new feature:

1. Analyze the current architecture.
2. Reuse existing systems where possible.
3. Preserve backward compatibility.
4. Avoid database conflicts.
5. Avoid duplicate functionality.
6. Add proper error handling.
7. Maintain security and performance.

FEATURE 1: ELIDEMS AI AGENT

Create a powerful AI Agent called:

ELIDEMS AI

The AI must function as an intelligent administrative assistant capable of understanding natural language commands from authorized users.

Authorized users:

- Owner
- Manager
- Admin

Examples:

- Block all users with overdue payments.
- Generate monthly reports.
- Suspend inactive accounts.
- Send reminders to learners.
- Approve teacher requests.
- Unlock learner accounts.
- Review flagged content.
- Monitor attendance.
- Generate analytics.

The AI must be capable of:

- Reading system data.
- Understanding commands.
- Performing authorized actions.
- Triggering existing buttons and workflows.
- Using available APIs.
- Creating summaries.
- Producing reports.
- Providing recommendations.

The AI must NEVER bypass role permissions.

All actions must be logged.

All actions must be reversible by Manager or Admin.

FEATURE 7: BREAK-ELIDEMS EVENT SYSTEM

Create a daily event feature called:

BREAK-ELIDEMS

Purpose:

Provide a global community learning and engagement session.

---

Participant Selection

Every day automatically select:

- 1 Manager
- 1 Admin
- 2 Volunteer Teachers
- 1 Volunteer Prefect

Teachers and prefects must have:

- Volunteered
- Submitted event details
- Healthy payment status

Selection rotates daily.

---

Event Types

Participants may host:

- Video calls
- Educational talks
- Announcements
- Motivation sessions
- News updates
- Community discussions
- Live learning sessions

---

Access Rules

Only users with healthy payment status may:

- Join
- Host
- Access event content

Teachers must also have active subscriptions for required premium features.

---

Event Schedule

Admin defines:

- Start time
- End time

Example:

10:00 AM – 12:00 PM

During event:

- Eligible users see BREAK-ELIDEMS button.
- Ineligible users cannot join.

After event ends:

- Event buttons disappear.
- Access closes automatically.
- Active sessions terminate gracefully.
- Platform returns to normal state.

---

FEATURE 8: TEMPORARY BENEFITS DURING BREAK-ELIDEMS

Admin can configure temporary feature access during BREAK-ELIDEMS.

Examples:

- Limited AI access
- Limited lessons
- Limited resources

Rules:

- Based on payment health score.
- Temporary access expires automatically.
- Original restrictions are restored after event ends.
