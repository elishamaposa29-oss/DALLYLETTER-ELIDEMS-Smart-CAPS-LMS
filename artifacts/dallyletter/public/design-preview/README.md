# Formal LMS Product Design Preview

This isolated design preview is part of the original **DALLYLETTER-ELIDEMS-Smart-CAPS-LMS** repository (not LMS4).

## Preview
When the original LMS Vercel project builds this branch, open `/design-preview/`.

## Design intent
- Formal institutional visual system: navy `#0F2A44`, gold `#C5A880` accents only, off-white `#F8F9FA`, white surfaces, charcoal text and thin grey dividers.
- Responsive desktop sidebar and compact mobile navigation.
- Role previews: Owner, Manager, Teacher, Learner and Prefect.
- Product surfaces: lessons/media, assignments/exercises, classes/timetable, attendance, RecordBook/reports, study groups, notices, people, CV/survey/transfer approvals, payments and settings.
- All sample metrics and records are illustrative. This preview does not call production APIs or perform real authentication, approvals, attendance writes, payment processing or data exports.
- Production authorization remains server-side; role switching here is presentation-only.

## Safety boundary
Design-only artifact. It does not replace the live LMS, change database schemas, update environment variables, or touch production deployment settings.
